🔐 QUICK FIX FOR LOGIN ISSUE
════════════════════════════════════════════════════════════════════════════════

The admin user creation might be failing silently. Here's the fastest fix:

🚀 STEP 1: Use Render Shell (Fastest)
════════════════════════════════════════════════════════════════════════════════

1. Go to Render Dashboard → Your Service
2. Click "SHELL" tab
3. Copy-paste this ENTIRE command:

cd saas_pos && python manage.py shell -c "
from django.contrib.auth import get_user_model
User = get_user_model()
User.objects.all().delete()
user = User.objects.create_user(
    username='admin',
    email='admin@example.com', 
    password='admin123',
    role='SUPERADMIN'
)
user.is_staff = True
user.is_superuser = True
user.save()
print('✅ Admin user created!')
"

4. Press Enter
5. You should see: ✅ Admin user created!
6. Now try login at: https://saas-restaurant-pos-system.onrender.com/admin/
