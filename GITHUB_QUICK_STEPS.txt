🎯 STEP-BY-STEP GUIDE (Copy-Paste Each Line):

1️⃣  OPEN POWERSHELL & NAVIGATE TO PROJECT
    ═════════════════════════════════════════
    cd C:\Users\vivan\Downloads\saas-restaurant-pos-system-main\saas-restaurant-pos-system-main

2️⃣  CONFIGURE GIT (First time only)
    ═════════════════════════════════════════
    git config --global user.name "Your Name"
    git config --global user.email "your@email.com"

3️⃣  INITIALIZE GIT REPO
    ═════════════════════════════════════════
    git init

4️⃣  ADD ALL FILES
    ═════════════════════════════════════════
    git add .

5️⃣  CREATE FIRST COMMIT
    ═════════════════════════════════════════
    git commit -m "Initial commit: SaaS Restaurant POS System - Production Ready"

6️⃣  CREATE GITHUB REPOSITORY
    ═════════════════════════════════════════
    1. Go to https://github.com
    2. Log in or sign up
    3. Click "+" (top right) → "New repository"
    4. Name: "saas-restaurant-pos-system"
    5. Make it "Public"
    6. Click "Create repository"

7️⃣  ADD REMOTE & PUSH
    ═════════════════════════════════════════
    (Replace YOUR-USERNAME with your GitHub username)
    
    git remote add origin https://github.com/YOUR-USERNAME/saas-restaurant-pos-system.git
    git branch -M main
    git push -u origin main

8️⃣  ENTER AUTHENTICATION
    ═════════════════════════════════════════
    When asked for password:
    
    Username: YOUR-GITHUB-USERNAME
    Password: USE PERSONAL ACCESS TOKEN (not password!)
    
    To create token:
    - GitHub → Settings → Developer settings → Personal access tokens
    - Generate new token
    - Select "repo" scope
    - Copy token and paste as password

❓ TROUBLESHOOTING

Problem: "fatal: not a git repository"
Solution: Make sure you're in the correct directory

Problem: "fatal: Could not read from remote repository"
Solution: Check username is correct in the remote URL

Problem: Authentication failed
Solution: Use Personal Access Token, not GitHub password
